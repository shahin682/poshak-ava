# پوشاک آوا — فروشگاه اینترنتی نمایشی (نمونه‌کار)

یک فروشگاه اینترنتی کامل پوشاک، ساخته‌شده با HTML و CSS و JavaScript ساده — بدون هیچ مرحله‌ی بیلد — تا مستقیم روی GitHub Pages منتشر شود.

## این چیست؟

نمونه‌کار نمایشی برای نشان دادن توانایی ساخت فروشگاه اینترنتی اختصاصی (کدنویسی‌شده، نه وردپرس). برند «پوشاک آوا» خیالی است و فروشگاه واقعی نیست؛ در سربرگ و پاصفحه‌ی سایت هم «نمونه نمایشی» نوشته شده است.

## چه چیزی دارد؟

- **صفحه اصلی:** هیرو، دسته‌بندی‌ها (زنانه / مردانه / اکسسوری)، محصولات منتخب، ویژگی‌ها و خبرنامه
- **فروشگاه:** ۱۲ محصول با جستجو، فیلتر دسته‌بندی، فیلتر سایز، محدوده‌ی قیمت و مرتب‌سازی
- **صفحه محصول:** انتخاب سایز و رنگ، تعداد، افزودن به سبد، مشخصات و محصولات مرتبط
- **سبد خرید:** تغییر تعداد، حذف، جمع اقلام، هزینه ارسال (بالای ۱٬۵۰۰٬۰۰۰ تومان رایگان) — با `localStorage` بین بازدیدها می‌ماند
- **تسویه حساب:** فرم اطلاعات و آدرس با اعتبارسنجی، دو روش پرداخت (نمایشی) و صفحه‌ی موفقیت با کد رهگیری
- **حساب کاربری:** ثبت‌نام نمایشی و پنل کاربر با فهرست سفارش‌های ثبت‌شده
- **درباره ما و تماس با ما:** معرفی فروشگاه و فرم تماس (نمایشی)
- **سئوی پایه:** متای توضیحات، Open Graph، JSON-LD فروشگاه پوشاک و HTML معنایی

## تصاویر

- عکس هیرو، عکس صفحه‌ی درباره ما و ۶ عکس محصول با هوش مصنوعی ساخته شده‌اند.
- ۶ تصویر محصول دیگر (مانتو، پیراهن، تونیک، جین، تیشرت، هودی) تصویرسازی SVG هستند، چون سرویس ساخت تصویر در زمان ساخت موقتاً در دسترس نبود؛ همه در همان پوشه‌ی `assets/images` قرار دارند و لینک خرابی وجود ندارد.

## انتشار روی GitHub Pages

1. محتوای این پوشه را در ریشه‌ی یک ریپوی گیت‌هاب بگذار.
2. در تنظیمات ریپو: Settings → Pages → Source روی «Deploy from a branch» و شاخه‌ی `main` (پوشه‌ی `/root`) باشد.
3. آدرس عمومی فروشگاه به شکل `https://USERNAME.github.io/REPO-NAME/` ساخته می‌شود.

## نکات نمایشی

- هیچ پرداختی انجام نمی‌شود؛ درگاه پرداخت واقعی متصل نیست.
- سفارش‌ها فقط در مرورگر خود بازدیدکننده ذخیره می‌شوند و به جایی ارسال نمی‌شوند.
- اطلاعات تماس، آدرس و قیمت‌ها ساختگی و مخصوص نمایش هستند.

## ساختار فایل‌ها

```
shop-sample/
├── index.html              # نقطه‌ی ورود (تک‌صفحه‌ای با مسیریابی هش)
├── README.md               # همین فایل
└── assets/
    ├── css/
    │   └── style.css       # همه‌ی استایل‌ها (فونت وزیرمتن با جایگزین سیستمی)
    ├── js/
    │   └── app.js          # داده‌ی محصولات، مسیریاب، سبد خرید، تسویه، حساب کاربری
    └── images/
        ├── hero.webp       # عکس هیرو
        ├── about.webp      # عکس صفحه‌ی درباره ما
        ├── p01-coat.svg … p06-hoodie.svg   # تصویرسازی محصولات
        └── p07-shirt.webp … p12-belt.webp  # عکس محصولات
```
